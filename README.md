Spring Boot Auth Backend (JWT) - Minimal Starter
------------------------------------------------
Files:
- pom.xml
- src/main/java/com/example/auth/... (controller, service, model, repository, security)
- src/main/resources/application.properties

How to run:
1. Configure src/main/resources/application.properties with your PostgreSQL credentials.
2. Build: mvn clean package
3. Run: mvn spring-boot:run
The server will start on port 8080.
